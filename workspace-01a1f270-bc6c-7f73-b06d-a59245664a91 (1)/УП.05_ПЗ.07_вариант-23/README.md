## Запуск в VS Code

Папка уже содержит готовые конфиги: `.vscode/launch.json`, `.vscode/tasks.json`, `.vscode/extensions.json`.

1. **Открыть проект:** VS Code → *File → Open Folder* → выбрать папку `УП.05_ПЗ.07_вариант-23`
   (не открывайте отдельный файл — тогда конфиги запуска не подхватятся).
2. **Терминал:** `Ctrl` + ` (обратный апостроф, слева от «1») → выполнить `node server.js`.
   Проверить, что Node установлен: `node -v` (должен быть номер версии, например `v20.11.0`).
3. **Остановить сервер:** `Ctrl + C` в терминале.
4. **Запуск кнопкой:** панель *Run and Debug* (`Ctrl + Shift + D`) → выбрать
   «Сервер варианта 23 (порт 3623)» → `F5`. Есть также «Эмуляция (порт 3624)» и
   составной запуск «Сервер + эмуляция».
5. **Задачи:** `Ctrl + Shift + P` → *Tasks: Run Task* → «Запустить сервер (3623)»,
   «Запустить эмуляцию (3624)», «Проверить сервер (PowerShell-скрипт)».
6. **Запросы без Postman:** установить расширение **REST Client** (`humao.rest-client`),
   открыть `requests.http` → над каждым блоком появится «Send Request». Ожидаемые коды
   подписаны в комментариях.
7. **Проверка сценариев:** терминал → `cd Проверка` → `powershell -ExecutionPolicy Bypass -File .\check-server.ps1`.
8. **Postman/Insomnia:** сервер должен работать в терминале VS Code; клиенты — отдельные программы.

Если при `node server.js` появляется `EADDRINUSE` — порт уже занят (сервер запущен в другом окне).
Освободить: `netstat -ano | findstr :3623` → `taskkill /PID <номер> /F`, либо просто изменить `PORT` в начале `server.js`.

## Быстрый старт

```bash
node server.js                       # реальный сервер, порт 3623
node mock-server.js                  # эмуляция, порт 3624

# прогон коллекции без Postman (нужен newman)
newman run тест-опрос-23.postman_collection.json -e тест-опрос-23.postman_environment.json
newman run тест-опрос-23.postman_collection.json --env-var baseUrl=http://localhost:3624
```

Оба прогона: **6 запросов, 0 ошибок, 6 проверок пройдено**.
